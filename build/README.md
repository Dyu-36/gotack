# build

Wails packaging assets. build/bin is the build output folder and is git-ignored.

| Folder | Contents |
| --- | --- |
| windows | icon.ico, info.json, wails.exe.manifest |
| darwin | Info.plist, entitlements |
| linux | desktop entry, packaging metadata |

Defaults are regenerated by the Wails CLI when missing. The application icon can
be copied from frontend/public/tack.ico.
