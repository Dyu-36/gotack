# Active Execution Plans

The canonical remaining-work plan is [Windows release completion](windows-release-completion.md). It owns implementation order, progress and final acceptance. The input-pipeline, IP-01/IP-02 and Hermes records remain supporting evidence; their historical ticks are not release approval.

Place one evolving plan here when work needs durable memory. Use
`docs/templates/exec-plan.md`, keep progress and validation current, and move
the plan to `../completed/` only after the result is verified.
